# Local Hook Event Contract v1

## Example JSONL record

```json
{"schema_version":1,"source":"claude-code","session_id":"abc-123","timestamp":"2026-10-25T10:00:00.000Z","event":"SessionStart","cwd":"C:\\work\\app","tool_name":""}
```

**Allowed event types:** `SessionStart`, `SessionEnd`, `PreToolUse`, `PostToolUse`, `PermissionRequest`, `Stop`.

**MVP fields:**
- `schema_version`: integer, must equal `1`.
- `source`: fixed `claude-code`.
- `session_id`: provider session identifier, max 128 bytes/characters in bridge.
- `timestamp`: UTC ISO-8601 generated by the bridge.
- `event`: one of listed lifecycle values.
- `cwd`: working directory metadata; may contain private project names; max 512 characters. **This is still potentially sensitive**, keep on-device.
- `tool_name`: name only (`Bash`, `Edit`, etc.), max 48 characters.

Explicitly excluded: prompts, transcripts, tool arguments/command text, file contents, keys, request headers and session token/auth material.

## State reduction
| Event | Initial UI mapping | Important caveat |
|---|---|---|
| SessionStart | working | Session may be idle soon after startup |
| PreToolUse | working | No conclusion about command success |
| PostToolUse | working | Completion of tool, not completion of task |
| PermissionRequest | waiting | May become stale after approval elsewhere |
| Stop | completed | Means response stopped; not proof of done |
| SessionEnd | completed | Session end without verification |
| Unknown | unknown or unchanged | New provider events must be versioned |

Do not show a 'Verified' badge until an explicit evidence collector can prove appropriate tests ran and passed for the same workspace revision.

## Security and retention
Local file: `%LOCALAPPDATA%\STXICHalo\events.jsonl`. Rust reads only the last 256 KiB and returns at most 250 parsed records. A log rotation/retention implementation is required before beta to prevent unlimited file growth. User may delete this file after disabling hooks. When exporting logs for support, redact paths/session IDs unless user explicitly opts in.
