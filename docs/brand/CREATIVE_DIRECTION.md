# Visual Creative Direction

**Keywords:** ambient, quiet signal, orbital geometry, black glass, restrained mint, precision, trustworthy.

## Hero composition
Canvas: deep obsidian with a soft glow behind a floating pill. Headline should be short and legible. Show a realistic expanded interface, not a fictional screenshot presenting unsupported live product features. Each hero mock should be labelled *concept* until implemented.

## Windows UI
Respect hardware display scaling, top-edge position, taskbar, snapping and active window focus. Unlike a macOS camera cutout, the Windows island should appear as a deliberate **floating companion** with soft depth and no fake camera housing.

## Design assets supplied
Open `assets/mockups/halo-brand-board.svg` and `assets/mockups/halo-hero.svg` in Figma or any SVG editor. Raster PNG counterparts are provided for quick preview. Colors and typography can be reconfigured via design tokens.

## Figma file structure recommendation
Page 01 Brand / Page 02 Foundations / Page 03 Components / Page 04 Compact states / Page 05 Expanded UI / Page 06 Settings and onboarding / Page 07 Marketing / Page 08 Redlines & specs. Components should use auto-layout and variables, not one flattened screenshot.

## Visual design done criteria
- Logo survives 20 px test and monochrome.
- Compact idle state looks intentional at 100%, 125%, 150% and 200% Windows scale.
- No blocking input in transparent regions.
- A warning and an informational event can be differentiated without color.
- "Demo" vs live measurements remain legible and obvious.
