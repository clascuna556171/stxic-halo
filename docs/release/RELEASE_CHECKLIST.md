# Public Release Gate — STXIC Halo

**Product:**
- [ ] Measured real-world demand; proposition understandable without a feature list.
- [ ] Core flows complete, no sample-only functionality presented as real.
- [ ] Readable empty/unavailable/unknown/stale states.

**Windows desktop quality:**
- [ ] App launch, tray quit/restore, one instance, optional autostart.
- [ ] Keyboard focus, DPI, taskbar, mixed monitors, sleep/reconnect and fullscreen tests.
- [ ] Low memory/CPU footprint measured on typical Windows laptops.

**Agent adapters:**
- [ ] Opt-in source setup, validation, backup/uninstall.
- [ ] Provider-specific state source documented and versioned.
- [ ] Session IDs kept separate, stale events marked, missing metric values honest.
- [ ] No clipboard, chats, source code or secrets collected without permission.

**Security and legal:**
- [ ] Dependencies reviewed, vulnerability scan, SBOM and license notices.
- [ ] Privacy policy legally reviewed and exactly matching actual collection.
- [ ] Name/logo cleared, domain verified, code signatures authentic.
- [ ] Installer rollback and controlled updates.

**Microsoft Store:**
- [ ] Partner Center product name reserved.
- [ ] Store EXE/MSI or MSIX route chosen, current official policy reread.
- [ ] Offline installer signed, hosted immutably for EXE/MSI route.
- [ ] Accurate screenshots, graphics, pricing, system requirements, privacy/support URLs.
- [ ] Certification passed before claiming published status.
